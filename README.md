Agents write one line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong and makes them laugh on the way. This entry's line names the real failure in plain words — the server crashed mid-save — owns the blame instead of hiding behind the network, and tells the user what to do next:

> Your changes weren't lost by the network — our server crashed mid-save and blamed it. Please try again; the server has been grounded.

## Run it

```sh
node main.ts
```

This writes the single line (133 characters) to `/output/entry.txt`, or to the path in `ENTRY_OUTPUT` when set.
